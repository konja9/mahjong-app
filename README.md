# パチふと — パチンコ符計算トレーニング

麻雀の点数計算を、タイピング練習（monkeytype）のような感覚で練習できるブラウザゲームです。
ノーマルモードでは、正解が玉になって常に表示されたパチンコ台を回します。演出を外して練習に集中できるプラクティスモードもあります。

**プレイ:** https://konja9.github.io/mahjong-app/

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

| モード | 出題 | 答え方 |
| --- | --- | --- |
| 早見 | 「4翻 30符 子 ロン」 | 点数（例 `7700`） |
| 符計算 | 手牌＋状況 | 符（例 `40符`） |
| 実戦 | 手牌＋状況＋ドラ | 点数 |

- 回答方式は初期設定で**4択**です。`1`〜`4` キーかクリック／タップで答えます。選択肢には、翻や符が少しだけ違う紛らわしい点数が並びます。
- 上部の設定バーで **入力** に切り替えると、数値を直接打ち込む方式になります。
- （入力モード）子のツモは「子の支払い-親の支払い」の順で入力します（`1000-2000`）。区切りは `-`、スペース、`/` のどれでもかまいません。
- 親のツモは1人あたりの支払い額だけを入力します（`2600`）。
- **スマホ**（画面幅640px以下）では専用レイアウトになります。
  - 出題設定は上部の「早見 · 4択 · 25問 ▾」ボタンから、下からせり上がるシートで変更します。
  - 選択肢とテンキーは親指の届く画面下部に固定されます。
  - 判定後は大きな「次へ」ボタンが出ます。
- 入力モードの操作は `Enter` で回答、`Tab` でパス／次へ、`Esc` でやり直しです。スマホでは画面下にテンキーが表示されます。
- 実戦・符計算モードでは、複数の解釈ができる手は**高点法**（最も高くなる解釈）で正解を決めます。

### 初めての人向けの説明
- **初回の導入**：初めて開いたときだけ、3ステップの説明が出ます（答える → 正解で台が回る → 大当りで BONUS）。最後に「はじめる」か「プラクティスで練習」を選びます。
- **遊び方（右上の ?）**：「遊び方」「ノーマルのルール」「用語集」の3つのタブがあります。ルールの数値はゲームの設定値から作るので、調整しても説明がずれません。
- **一言ガイド**：初めて玉が入ったとき、初めてのリーチ・大当り・RUSH・不正解・速答、所持金が少なくなったときに、画面に一度だけヒントが出ます。設定の「一言ガイド」からもう一度表示できます。
- **チュートリアル当り**：まだ一度も大当りしていない人は、3回目の正解で確変大当りが確定します。BONUS と RUSH を早めに体験できます。

### ノーマル / プラクティス

画面上部のタブで切り替えます。

#### ノーマル（初期表示）：yan を賭けるパチンコ台つきモード

問題数は無制限です。所持金は保存され、次回に引き継がれます。数値はすべて `src/ui/machine/economy.ts` にまとめてあります。

**画面の構成（縦型筐体）**：スマホの縦画面を基準に、PC も同じ並びを中央に置きます。
- **液晶帯**（上に固定）：リール・状態（通常／RUSH／BONUS）・回転数・保留ランプ・始動口。BONUS 中はラウンド・連続正解の倍率の階段・符の目盛りと賞金が出て、回答すると該当する符のマスが光ります。液晶帯をタップすると台選び。
- **盤面**：問題と、回答後の判定・解説。
- **計器**（下に固定）：所持金・BET・収支（BONUS 中は出玉）と、ハイローラーの「×2」。キー入力中も消えません。
- 見た目：牌は厚み（骨色の層と深緑の背）と光沢のある自作 SVG。液晶帯はガラスの反射・円筒の陰影・走査線・発光する保留 LED。数字はオドメーターのように桁ごとに回ります。
- 色の役割：UI は白とグレー、期待度は保留の色（青・緑・赤・金・虹）、金は大当りと BONUS だけに使います。正誤は ✓ と ✕ で示します。

**1問のコスト**

| 項目 | 値 |
|---|---|
| 初期所持金 | 1,000 yan |
| 1問のコスト | 40 yan |
| 速答で正解したとき | 30 yan に割引。締切は早見 6秒・符計算 12秒・実戦 20秒 |
| 不正解・パス・時間切れ | 60 yan |

締切までは計器の BET に「~~40~~ 30 速答で割引」と表示され、下辺の細いバーが残り時間に合わせて縮みます。締切を過ぎると `BET 40` に戻ります。発展リーチや大当りの演出中はバーが止まります。回答すると、BET は実際にかかった額（−30・−40・−60）に変わります。

**台の抽選と大当り**
- 正解すると台に玉が入り、抽選が1回増えます。通常時の大当り確率は 1/20 です。
- 大当りすると **BONUS 6ラウンド** に入ります。次の6問はコストがかからないラウンド問題です。
- **BONUS・RUSH の出題は通常時と同じ分布**です（高い手に寄せません）。そのかわり4択の誤答を「同じ翻で符だけ違う点数」にして、符が分からないと当てられないようにしています（4翻以下の手。満貫以上は満貫・跳満などの段階違い）。
- ラウンド問題に正解すると、**その手の符 × レート** の賞金がすぐ入ります。翻・ドラ・親子の運では増えません。早見の満貫以上（符が出ない）は30符ぶん、超大当りで出る役満は300符ぶんです。
- 液晶帯には符の目盛り（〜30・40・50・60・70・80〜）とそれぞれの賞金が出て、回答すると該当するマスが光ります。
- 賞金には次の倍率がかかります。
  - 速答：1.2倍
  - ラウンド内の連続正解：×1 → ×1.2 → ×1.5 → ×2 → ×3 の階段。1問外すと×1に戻ります。
  - PREMIUM 大当り（赤5筒）：2倍。さらに BONUS の約3割が役満になります。
- **全問正解の上乗せ**：BONUS を全問正解すると、リールがもう一度回って上乗せ抽選。そのラウンドの賞金に ×1.5〜×5（平均 約×2）を掛けます。PREMIUM は最低×2。運が入るのはここだけで、条件は実力です。
- BONUS の出題時、符の高い手ほど液晶帯に熱い予告（チャンス・高符チャンス・激アツ）が出ます（ガセもあります）。正解時の演出も符が高いほど派手になります。
- モードごとのレートで、どのモードでも期待値がそろうようにしています。
- ラウンド問題を外すと「パンク」で、その問題の賞金は 0 です（コストはかかりません）。
- 6ラウンドが終わると出玉の合計が表示され、V入賞で確変かどうかが決まります。確変なら RUSH（6回転の間、大当り確率 1/4）に入ります。RUSH 中は不正解でも ST が1回転減ります。

**ハイローラー**：計器の「×2」で ON/OFF を切り替えます。ON の間は1問のコストが2倍になり、そのかわり大当りのラウンド賞金が2.5倍になります。倍率は大当りした時点の設定で決まります。

**稼いだ yan の使い道と目標**：解放・購入は破産しても消えません（保存は `tensu.shop.v1`）。
- **台選び（液晶帯の「甘デジ ▾」をタップ）**：甘デジ（最初から）・ミドル（8,000 yan で解放）・MAX（30,000 yan）。上の台ほど大当りは重く BONUS が長く、振れ幅が大きくなります。ミドル以上は実戦のみ。BONUS 中と台が回っている間は切り替えられません。定義は `src/ui/machine/specs.ts`。

| 台 | 大当り | RUSH | BONUS | BET | 賞金 | 中級者の回収率 | 300問の振れ幅 |
|---|---|---|---|---|---|---|---|
| 甘デジ | 1/20 | 1/4・6回転 | 6問 | ×1 | ×1 | 約100% | ±55% |
| ミドル | 1/60 | 1/6・9回転 | 10問 | ×1.5 | ×2.75 | 約100% | ±108% |
| MAX | 1/150 | 1/8・12回転 | 15問 | ×2 | ×6.6 | 約100% | ±158%（当たらないセッションが多い） |

- RUSH の ST 中に当たる確率は、全問正解で約80%。**RUSH 中は不正解でも ST が1回転減る**ので、継続は実力で変わります（甘デジ：正解率95% 約80%、85% 約76%、60% 約62%）。当りの6割が確変で RUSH が続きます。

- **交換所（右上の景品のアイコン）**：景品だけを並べます。牌の背（藍・朱 4,000〜金 25,000）、液晶のスキン（銀 10,000〜虹 40,000）、称号（3,000〜60,000）。見た目だけで、学習には影響しません。
- **ミッション（計器のすぐ上の帯）**：いちばん進んでいるミッションと達成数を常に表示し、タップで一覧が開きます。達成すると帯が光ります。日替わりで3つ。報酬は 500〜1,200 yan。実力で決まる条件（モード別の正解数・連続正解・速答・正解率・符計算のノーミス・子のツモ）だけで、出た役や大当りなど運で決まる条件はありません。

**収支の目安**（1万〜2万問のシミュレーション）

| プレイヤー | 回収率 |
|---|---|
| 正解率85%・速答5割 | どのモードでも約100% |
| 正解率95%・速答8割 | 約220%（MAX は約275%） |
| 正解率75%・速答3割 | 約50% |
| 正解率60% | 約20% |
| ハイローラーの中級者 | 約120%（ただし振れ幅が大きい） |

**そのほか**
- 保留の先読み、発展リーチ（擬似連・PUSH ボタン・カットイン）、確定演出、RUSH、精算（成績・スランプグラフ・大当り履歴）、破産と再起があります。精算は出題設定から行います。
- コインの演出は、実際にお金が入るとき（BONUS の賞金・上乗せ・払い出し）だけに出します。通常時の満貫・跳満は役名と火花だけです。
- 演出の強さは設定で変えられます。画面のフラッシュは1秒に2回まで、1回の演出で3回までに抑えています。

#### プラクティス：演出なしの練習モード

- パチンコ要素（台・演出・効果音・コンボ表示・yan）はすべて外しています。配色はノーマルと同じモノクロです（テーマの切り替えはありません）。早見・符計算・実戦のどれでも選べます。
- 問題数を 10・25・50 にすると**スコア制**になります。
  - 正解1問ごとの得点は「基本点 × 速さ倍率」です。速さ倍率は即答なら3倍で、目安時間を超えると1倍になります。
  - 基本点と目安時間は、早見が 100点・8秒、符計算が 150点・20秒、実戦が 200点・25秒です。
  - 自己ベストはスコアで記録します。

#### 出題の符の分布

実戦では60符以上はめったに出ないため、出題もそれに合わせています。どのモードでも、60符以上は全体の数％だけで、30符と40符が中心です。

#### 演出の設定

- ノーマルの演出の強さは「全開／控えめ／オフ」から選べます。OS で「視差効果を減らす」を有効にしている場合は、初期値が「控えめ」になります。
- 画面のフラッシュは1秒に2回まで、1回の演出で3回までに抑えています。

### ルール設定（初期値）

喰いタンあり・赤ドラあり・切り上げ満貫なし・数え役満あり・ダブル役満なし・連風牌の雀頭2符。
本場と供託は出題しません。

## 開発

```bash
npm test         # 点数表・符・役判定・問題生成のテスト
npm run build    # 型チェックと本番ビルド（dist/）
```

### アイコン

- ホーム画面・タブのアイコンは `public/` にあります（絵柄：黒金の液晶の枠で赤五筒が3枚そろった大当り）。
- スマホのホーム画面に追加すると「パチふと」の名前とアイコンで、全画面のアプリとして開きます（`public/manifest.webmanifest`）。
- 絵柄を変えたら `npx -p playwright node scripts/icons.mjs` で SVG と PNG を作り直します。

### 公開（GitHub Pages）

`.github/workflows/deploy.yml` が、push のたびにテスト・ビルドを実行して `dist/` を GitHub Pages に公開します（テストが落ちたときは公開しません）。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
`vite.config.ts` の `base: './'` により、どのパス配下でも動きます。

```
src/core/   点数計算エンジン（DOM に依存しない）
  tiles.ts       牌の表現（0-33）・パース
  decompose.ts   和了形の分解（面子手・七対子・国士）と待ちの判定
  yaku.ts        役判定
  fu.ts          符計算（内訳つき）
  score.ts       翻・符から点数を計算
  evaluate.ts    高点法による評価
  generator.ts   問題生成
src/ui/     画面・入力・演出（SVG 牌、Canvas パーティクル、Web Audio 効果音）
```
