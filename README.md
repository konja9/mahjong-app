# tensu. — 麻雀点数計算トレーナー

麻雀の点数計算を、タイピング練習（monkeytype）のような感覚で練習できるブラウザゲームです。
ノーマルモードでは、正解が玉になって常に表示されたパチンコ台を回します。演出を外して練習に集中できるプラクティスモードもあります。

**プレイ:** https://konja9.github.io/mahjong-app/

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

| モード | 出題 | 答え方 |
| --- | --- | --- |
| 早見 | 「30符4翻 子 ロン」 | 点数（例 `7700`） |
| 符計算 | 手牌＋状況 | 符（例 `40符`） |
| 実戦 | 手牌＋状況＋ドラ | 点数 |

- 回答方式は初期設定で**4択**です。`1`〜`4` キーかクリック／タップで答えます。選択肢には、翻や符が少しだけ違う紛らわしい点数が並びます。
- 上部の設定バーで **入力** に切り替えると、数値を直接打ち込む方式になります。
- （入力モード）子のツモは「子の支払い-親の支払い」の順で入力します（`1000-2000`）。区切りは `-`、スペース、`/` のどれでもかまいません。
- 親のツモは1人あたりの支払い額だけを入力します（`2600`）。
- **スマホ**（画面幅640px以下）では専用レイアウトになります。
  - 出題設定は上部の「早見 · 4択 · 25問 ▾」ボタンから、下からせり上がるシートで変更します。
  - 選択肢とテンキーは親指の届く画面下部に固定されます。
  - 判定後は大きな「次へ」ボタンが出ます。
- 入力モードの操作は `Enter` で回答、`Tab` でパス／次へ、`Esc` でやり直しです。スマホでは画面下にテンキーが表示されます。
- 実戦・符計算モードでは、複数の解釈ができる手は**高点法**（最も高くなる解釈）で正解を決めます。

### ノーマル / プラクティス

画面上部のタブで切り替えます。

**ノーマル（初期表示）**：パチンコ台つきのモードです。点数やポイントのような要素はありません。

- **台パネル**：PC では画面右、タブレットでは上部、スマホでは問題の上に常に表示されます。
- **正解＝始動口に入賞**：答えから玉が飛んで始動口に入り、保留が1つ増えます（最大4つ）。満貫以上の手を当てると電チューが開いて保留が2つ増えます。
- 保留がある間は、回答と並行して台が自動で回ります。
  - 通常時の大当り確率は 1/8 です。
  - 抽選結果は入賞した時点で決まっていて、保留の色が熱いほど当たりに近くなります（先読み）。
- **リーチ**：左右の図柄がそろうとリーチです。熱いリーチや当りのときは画面中央で発展リーチになります（擬似連・PUSH ボタン・カットイン・巨大な中牌のギミック）。この間は回答と制限時間が止まり、タップで飛ばせます。
  - キリン柄・虹・金 PUSH・虹保留は当りのときしか出ません（確定演出）。
- **大当り**：図柄がそろう → 大当り演出 → ラウンド 1〜10 → V 入賞の順に進みます。奇数図柄なら確変（RUSH）に入り、7萬がそろうと PREMIUM 演出になります。
- **確変（RUSH）**：
  - 8回転の間、大当り確率が 1/2 に上がります。
  - 出題では**役満が出やすくなります**（実戦は約35%が役満、早見は11翻・13翻が増えます）。
  - 5連以上で超確変の演出になります。
- **データカウンター**：回転数・大当り回数・最大 RUSH 連チャンを表示し、まとめ画面にも出します。
- **連続正解**：連続正解の数に合わせてヒット音の音程が上がります。10連・20連では節目の演出が出ます。

**プラクティス**：パチンコ要素（台・演出・効果音・コンボ表示）をすべて外した練習用のモードです。早見・符計算・実戦のどれでも選べます。

**演出の設定**：
- ノーマルの演出の強さは「全開／控えめ／オフ」から選べます。OS で「視差効果を減らす」を有効にしている場合は、初期値が「控えめ」になります。
- 画面のフラッシュは1秒に2回まで、1回の演出で3回までに抑えています。

### ルール設定（初期値）

喰いタンあり・赤ドラあり・切り上げ満貫なし・数え役満あり・ダブル役満なし・連風牌の雀頭2符。
本場と供託は出題しません。

## 開発

```bash
npm test         # 点数表・符・役判定・問題生成のテスト
npm run build    # 型チェックと本番ビルド（dist/）
```

### 公開（GitHub Pages）

`.github/workflows/deploy.yml` が、push のたびにテスト・ビルドを実行して `dist/` を GitHub Pages に公開します（テストが落ちたときは公開しません）。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
`vite.config.ts` の `base: './'` により、どのパス配下でも動きます。

```
src/core/   点数計算エンジン（DOM に依存しない）
  tiles.ts       牌の表現（0-33）・パース
  decompose.ts   和了形の分解（面子手・七対子・国士）と待ちの判定
  yaku.ts        役判定
  fu.ts          符計算（内訳つき）
  score.ts       翻・符から点数を計算
  evaluate.ts    高点法による評価
  generator.ts   問題生成
src/ui/     画面・入力・演出（SVG 牌、Canvas パーティクル、Web Audio 効果音）
```
