# tensu. — 麻雀点数計算トレーナー

麻雀の点数計算を、タイピング練習（monkeytype）のような感覚で練習できるブラウザゲームです。
正解するとパチンコ風の演出（保留変化・リーチ・激アツ・確変・大当り）が入ります。

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

| モード | 出題 | 答え方 |
| --- | --- | --- |
| 早見 | 「30符4翻 子 ロン」 | 点数（`7700`） |
| 符計算 | 手牌＋状況 | 符（`40`） |
| 実戦 | 手牌＋状況＋ドラ | 点数 |

- 子のツモは「子の支払い-親の支払い」の順で入力します（`1000-2000`）。区切りは `-`、スペース、`/` のどれでもかまいません。
- 親のツモは1人あたりの支払い額だけを入力します（`2600`）。
- 操作は `Enter` で回答、`Tab` でパス／次へ、`Esc` でやり直しです。スマホでは画面下にテンキーが表示されます。
- 実戦・符計算モードでは、複数の解釈ができる手は**高点法**（最も高くなる解釈）で正解を決めます。

### 演出（玉）

- **保留ランプ**の色で、その問題で得られる玉の倍率が決まります（青×1・緑×1.5・赤×2・金×3・虹×5）。正解すると保留が昇格することがあります。
- **5連続正解**で確変に入り、玉が2倍になります。1問でも間違えると確変は終わります。
- 満貫以上の手や金・虹の保留では、大当り演出が入ります。役満のときは画面がいったん止まったあと、虹色の演出に切り替わります。
- 演出の強さは設定で「全開／控えめ／オフ」から選べます。OS で「視差効果を減らす」を有効にしている場合は、初期値が「控えめ」になります。
- 画面のフラッシュは1回だけ、輝度も抑えてあります。

### ルール設定（初期値）

喰いタンあり・赤ドラあり・切り上げ満貫なし・数え役満あり・ダブル役満なし・連風牌の雀頭2符。
本場と供託は出題しません。

## 開発

```bash
npm test         # 点数表・符・役判定・問題生成のテスト
npm run build    # 型チェックと本番ビルド（dist/）
```

`vite.config.ts` の `base: './'` により、`dist/` をそのまま GitHub Pages などの静的ホスティングに置けます。

```
src/core/   点数計算エンジン（DOM に依存しない）
  tiles.ts       牌の表現（0-33）・パース
  decompose.ts   和了形の分解（面子手・七対子・国士）と待ちの判定
  yaku.ts        役判定
  fu.ts          符計算（内訳つき）
  score.ts       翻・符から点数を計算
  evaluate.ts    高点法による評価
  generator.ts   問題生成
src/ui/     画面・入力・演出（SVG 牌、Canvas パーティクル、Web Audio 効果音）
```
