# パチふと — パチンコ符計算トレーニング

麻雀の点数計算を、タイピング練習（monkeytype）のような感覚で練習できるブラウザゲームです。
パチンコモードでは、正解が玉になって常に表示されたパチンコ台を回します。演出を外して、手牌を段階的に解きながら数え方を身につける稽古モードもあります。

**プレイ:** https://konja9.github.io/mahjong-app/

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

| モード | 出題 | 答え方 |
| --- | --- | --- |
| 早見 | 「4翻 30符 子 ロン」 | 点数（例 `7700`） |
| 符計算 | 手牌＋状況 | 符（例 `40符`） |
| 実戦 | 手牌＋状況＋ドラ | 点数 |

- 回答方式は初期設定で**4択**です。`1`〜`4` キーかクリック／タップで答えます。選択肢には、翻や符が少しだけ違う紛らわしい点数が並びます。
- **符計算**は4択ではなく、`20符 25符 30符 40符 50符 60符` の**いつも同じ昇順の6つのボタン**で答えます（`1`〜`6` キー。スマホでは2列3段）。正解の近くから誤答を選ぶ4択だと、手牌を見ずに真ん中を選ぶだけで当たってしまうためです。
- **出題設定**：上部の種目タブ（早見・符計算・実戦）の右上にある要約ボタン（例「選択 · 25問 ▾」）を押すと、設定パネルが開きます（PC は画面上部の中央、スマホは下からせり上がるシート）。
  - パネルは「答え方（回答）」「出題（問題数・鳴き）」「状況（親子・和了）」の見出しで分かれています。問題数と鳴きは稽古だけです。
  - 使えない選択肢は消さずに押せない形で出し、理由を下に添えます（例：段階は符計算だけ、七対子は門前の手だけ）。
  - 選ぶとすぐに反映されます。`Esc`・パネルの外・「閉じる」で閉じます。開いている間はキーで回答しません。
- 回答を **入力** に切り替えると、数値を直接打ち込む方式になります。
- （入力モード）子のツモは「子の支払い-親の支払い」の順で入力します（`1000-2000`）。区切りは `-`、スペース、`/` のどれでもかまいません。
- 親のツモは1人あたりの支払い額だけを入力します（`2600`）。
- **スマホ**（画面幅640px以下）では専用レイアウトになります。
  - 選択肢とテンキーは親指の届く画面下部に固定されます。
  - 判定後は大きな「次へ」ボタンが出ます。
- 入力モードの操作は `Enter` で回答、`Tab` でパス／次へ、`Esc` で入力を消します。スマホでは画面下にテンキーが表示されます。
- `Esc` は入力を消すだけで、問題の入れ替えやセッションのやり直しはしません。稽古を最初からやり直すときは、出題設定の「最初からやり直す」を使います。
- BONUS 中は、問題や台が入れ替わる操作（出題設定・ルールの変更・成績を見る・所持金のリセット）はできません。
- 実戦・符計算モードでは、複数の解釈ができる手は**高点法**（最も高くなる解釈）で正解を決めます。

### 初めての人向けの説明
- **スタート画面**：起動するたびに最初に出ます。ロゴとパチふとくんのひとこと、「パチンコ」（所持金つき）・「稽古」のボタン。初めての起動では「チュートリアル」を一番大きく出し、「チュートリアルをとばす」も出します。2回目以降は「チュートリアルを見る」の小さなボタンになります。
  - ゲームに戻るには、PC はヘッダーのロゴ、スマホは設定の「スタート画面」、Android は戻るボタン（閉じるものがないとき）。BONUS や大当りの演出の間は戻れません。スタート画面を出している間は、台の次の回転と速答の時間を止めます。
  - スタート画面からゲームに入るときは、ローディング画面（演出）をはさみます。リールが回って 7・7・7 がそろい、バーが満ちたら「タップして進む」。世界観の一文（`src/ui/start.ts` に18本。稽古なら道場向け、パチンコなら賭場向けの文を優先）を読めるよう、自動では進みません。バーが満ちる前のタップはバーを満たすだけで、次のタップでゲームへ。Enter・Space でも進めます。演出オフ・動きを減らす設定では動かしません。
- **チュートリアル（パチふとくんの案内）**：スタート画面の「チュートリアル」から始まります。案内役は麻雀牌スロットの妖精「パチふとくん」。舞台は、人の値打ちがギャンブルの腕だけで決まる「ギャンブル世紀末」で、符計算もままならない新顔（プレイヤー）をギャンブル王に育てる、という設定です。
  - 画面を暗くして操作する場所だけを光らせ（スポットライト）、指のアイコンで押す場所を示します。光った場所以外は押せず、実際に操作すると次へ進みます。セリフは吹き出しに1文字ずつ出て、タップで進みます。
  - 暗さは場面で変えます：セリフだけ 0.62／光らせて説明 0.5／**光らせて操作させる場面 0.3**（金色の枠と「タップ！」の札、吹き出しに「光っているところを押してね」）。
  - 吹き出しは、光らせる対象の上下の空いている側に、収まる高さで置きます（`src/ui/tutorial/layout.ts`）。答えさせる場面は、問題に重ならないよう画面の上端の帯に出します。スマホでは顔を小さくして場所を空けます。自由に遊ぶ場面は上端の小さな帯です。画面の下端からは回答欄と同じだけ（6vh、24〜56px）離し、ナビゲーションバーのあるスマホでも被らないようにしています。
  - 章は4つ：プロローグ（世界観）／パチンコの基本（決まった1問を解き、あと2問の正解で大当り → 2問だけの短い BONUS を遊ぶ。この間の BET はなし。そのあと出題の早見・符計算・実戦の違いと、経験値の帯を紹介）／稽古（重点学習の段階を1つ答える）／道具の場所（出題設定・交換所・物語の本・ヘルプ・設定）。
  - 吹き出しの右上の「スキップ」で、この章または全部をとばせます（吹き出しごと対象を避けるので、光らせたボタンに重なりません）。チュートリアル中は画面上端の一言は出しません。設定の「チュートリアル」から、全部または章を選んでいつでも見直せます。
  - 台本（セリフ・光らせる場所・進み方）は `src/ui/tutorial/script.ts` にステップのリストとしてまとめています。仕組みは `runner.ts`、キャラの絵（自作の SVG・表情5種）は `chara.ts`。
- **遊び方（右上の ?）**：「遊び方」「パチンコのルール」「用語集」の3つのタブがあります。ルールの数値はゲームの設定値から作るので、調整しても説明がずれません。
- **一言ガイド**：パチふとくんの顔つき・口調で、初めて玉が入った・リーチ・大当り・RUSH・不正解・速答・所持金が少ない、に加えて、電チューの手前と開放・BONUS の賞金（符）・連続の倍率・パンク・ラウンド上乗せ・全問正解・RUSH 中の不正解・交換所や台を解放できる所持金・Lv が上がったときに、画面に一度だけヒントが出ます。「詳しく」を押すとヘルプの該当するカードが開きます。設定の「一言ガイド」からもう一度表示できます。
- **符の数え方（ヘルプの「符の数え方」タブ）**：数える順番（決まった形 → 副底 → 和了り方 → 面子 → 雀頭 → 待ち → 切り上げ）、刻子・槓子の符の表、待ちの符と高点法、例題3つ。例題の符は点数エンジンで計算するので、説明と正解がずれません。
- **解説**：手牌を面子ごとに区切った図の下に各ブロックの符を出し、和了牌と待ちの形を示します。符の内訳は 0符の項目も含めて数える順にすべて並べ、「鳴いているので付かない」「ロンで完成＝明刻扱い」などの理由を添えます。分け方で符が変わる手は「別の分け方」と、点数が高い方を正解にしていること（高点法）を示します。見出しの「符の数え方 ›」でヘルプを開けます。
- **ヘルプ（？）**：基本・符の数え方・BONUS・RUSH・お金と景品・用語のタブ。仕組みごとに、実際の画面と同じ見た目の小さな図つきのカードで説明します。基本タブの先頭は「このゲームの目的」。
- **チュートリアル当り**：まだ一度も大当りしていない人は、3回目の正解で確変大当りが確定します。BONUS と RUSH を早めに体験できます。

### パチンコ / 稽古

画面上部のタブで切り替えます。

#### パチンコ（初期表示）：yan を賭けるパチンコ台つきモード

問題数は無制限です。所持金は保存され、次回に引き継がれます。数値はすべて `src/ui/machine/economy.ts` にまとめてあります。

**画面の構成（縦型筐体）**：スマホの縦画面を基準に、PC も同じ並びを中央に置きます。
- **液晶帯**（上に固定）：リール・状態（通常／RUSH／BONUS）・回転数・保留ランプ・始動口。BONUS 中はラウンド・連続正解の倍率の階段・符の目盛りと賞金が出て、回答すると該当する符のマスが光ります。液晶帯をタップすると台選び。
- **盤面**：問題と、回答後の判定・解説。
- **稽古の「おしい！」**：段階練習で途中の段階を間違えても、最後の「点数は？」に正解していれば、判定は「不正解」ではなく「おしい！」（△・橙）と出ます。記録（復習・苦手）は不正解として残ります。
- **計器**（下に固定）：所持yan・BET・**本日の収支**（BONUS 中は出玉）。キー入力中も消えません。本日の収支は BET と BONUS の賞金だけを数え（交換所の買い物・破産・所持金のリセットは含めない）、**朝5時**に0に戻ります。「成績を見る」の収支は、その遊びの分（今回の収支）です。
- 見た目：牌は厚み（骨色の層と深緑の背）と光沢のある自作 SVG。液晶帯はガラスの反射・円筒の陰影・走査線・発光する保留 LED。数字はオドメーターのように桁ごとに回ります。
- 色の役割：UI は白とグレー、期待度は保留の色（青・緑・赤・金・虹）、金は大当りと BONUS だけに使います。正誤は ✓ と ✕ で示します。

**1問のコスト**

| 項目 | 値 |
|---|---|
| 初期所持金 | 1,000 yan |
| 1問のコスト | 40 yan |
| 速答で正解したとき | 20 yan（半額）に割引。締切は早見 6秒・符計算 12秒・実戦 20秒 |
| 不正解・パス・時間切れ | 60 yan |

締切までは計器の BET に「~~40~~ 20 速答で割引」と表示され、下辺の細いバーが残り時間に合わせて縮みます。締切を過ぎると `BET 40` に戻ります。発展リーチや大当りの演出中はバーが止まります。回答すると、BET は実際にかかった額（−20・−40・−60）に変わります。

**台の抽選と大当り**
- 正解すると台に玉が入り、抽選が1回増えます。通常時の大当り確率は 1/20 です。
- **電チュー開放**：連続正解が続くと、正解1回で玉が2個入ります（早見 15連・符計算 6連・実戦 4連から。早見は連続正解しやすいので多く必要）。外すと1個に戻ります。問題数の横に ●● が出ます。
- 大当りすると **BONUS 6ラウンド** に入ります。そのとき回答待ちの問題から6問が、コストのかからないラウンド問題になります（回答済みなら次の問題から）。
- **BONUS・RUSH の出題は通常時と同じ分布**です（高い手に寄せません）。そのかわり4択の誤答を「同じ翻で符だけ違う点数」にして、符が分からないと当てられないようにしています（4翻以下の手。満貫以上は満貫・跳満などの段階違い）。
- ラウンド問題に正解すると、**その手の符のマスの額** の賞金がすぐ入ります。マスは 20・25・30・40・50・60符の6つで、出にくく数えるのが難しい**高い符ほど大きく**、30符を1として 20 ×0.7・25 ×0.9・30 ×1・40 ×1.5・50 ×2.3・60 ×3.3 です。翻・ドラ・親子の運では増えません。早見の満貫以上（符が出ない）は30符のマス、超大当りで出る役満は30符の10倍です。
- 液晶帯には6つのマスとそれぞれの賞金が出て、回答すると該当するマスが光ります。
- 賞金には次の倍率がかかります。
  - ラウンド内の連続正解：×1 → ×1.05 → ×1.1 の階段。1問外すと×1に戻ります。
  - PREMIUM 大当り（赤5筒）：2倍。さらに BONUS の約3割が役満になります。
  - 速答は BET の割引（半額）で得をするので、賞金には倍率をかけません。
- **ラウンド上乗せ**：BONUS 中に満貫以上を正解すると問題数が増えます（満貫・跳満 +1R、倍満・三倍満 +2R、役満 +3R。1回の BONUS で最大 +3R）。賞金は符のままで、練習できる問題が増えるのがメリットです。液晶帯の丸が増え、判定の行に「満貫 → +1R」と出ます。全問正解の条件には上乗せ分も含みます。
- **全問正解の上乗せ**：BONUS を全問正解すると、リールがもう一度回って上乗せ抽選。そのラウンドの賞金に ×1.1〜×1.5（平均 約×1.17）を掛けます。PREMIUM は ×1.3〜×2。運が入るのはここだけで、条件は実力です。
- BONUS の出題時、符の高い手ほど液晶帯に熱い予告（チャンス・高符チャンス・激アツ）が出ます（ガセもあります）。正解時の演出も符が高いほど派手になります。
- モードごとのレートで、どのモードでも期待値がそろうようにしています。
- ラウンド問題を外すと「パンク」で、その問題の賞金は 0 です（コストはかかりません）。
- 6ラウンドが終わると出玉の合計が表示され、V入賞で確変かどうかが決まります。確変なら RUSH（6回転の間、大当り確率 1/4）に入ります。RUSH 中は不正解でも ST が1回転減ります。

**稼いだ yan の使い道と目標**：解放・購入は破産しても消えません（保存は `tensu.shop.v1`）。
- **台選び（液晶帯の「甘デジ ▾」をタップ）**：甘デジ（最初から）・ミドル（3,000 yan で解放）・MAX（10,000 yan）。上の台ほど大当りは重く BONUS が長く、振れ幅が大きくなります。ミドル以上は実戦のみ。BONUS 中と台が回っている間は切り替えられません。定義は `src/ui/machine/specs.ts`。

| 台 | 大当り | RUSH | BONUS | BET | 賞金 | 中級者の回収率 | 300問の振れ幅 |
|---|---|---|---|---|---|---|---|
| 甘デジ | 1/20 | 1/4・6回転 | 6問 | ×1 | ×1 | 約113〜118% | ±39% |
| ミドル | 1/60 | 1/6・9回転 | 10問 | ×1.5 | ×2.89 | 約121% | ±74% |
| MAX | 1/150 | 1/8・12回転 | 15問 | ×2 | ×6.72 | 約118% | ±92%（当たらないセッションが多い） |

- RUSH の ST 中に当たる確率は、全問正解で約80%。**RUSH 中は不正解でも ST が1回転減る**ので、継続は実力で変わります（甘デジ：正解率95% 約80%、85% 約76%、60% 約62%）。当りの6割が確変で RUSH が続きます。

- **交換所（右上の景品のアイコン）**：景品だけを並べます。**称号・スキン・BGM** のタブに分かれ、タブに所持数が出ます。見た目と音だけで、学習には影響しません。
  - 牌の背（藍・朱 1,500〜金 8,000）、液晶のスキン（銀 3,500〜虹 12,000）。
  - BGM（BONUS・RUSH の曲）：スタンダード（最初から）・ユーロビート 2,500・和風 4,000・チップチューン 5,000。試聴できます。
  - 称号：買う称号 13種（500〜20,000）と、**実力の称号** 12種。実力の称号は買えず、パチンコで条件を満たすと自動で手に入ります（初陣・完全試合＝BONUS の全問正解、連チャン職人・不動心・無双＝20・50・100 連続正解、符の求道者・符の達人・早見の鬼・実戦派・電光石火・ツモ計算士＝累計正解数、精密機械＝1回の遊びで 100 問以上を正解率 95% 以上）。運で決まる条件はありません。
  - 装備した称号は、計器の上の経験値の帯（Lv の横）にプレートで表示されます。プレートの色はレア度（コモン＝グレー、レア＝青、エピック＝紫、レジェンド＝ホログラム）。買う称号は値段で、実力の称号は条件の難しさでレア度が決まります。
- **経験値と Lv（計器のすぐ上の帯）**：yan を稼ぐと経験値がたまります（BONUS の賞金・上乗せと同じ量。BET・買い物・破産では減らない）。パチンコの通常の問題の正解でも 3 入ります。稽古でも、正解すると少しだけ（1問を全部正解で 10、段階練習は正解の割合で）たまります。Lv1 から始まり上限なし。帯には Lv・装備した称号・バー・次の Lv までの量と、読んでいない話があれば NEW。タップで物語の本が開きます。日替わりミッションは廃止しました。
  - 次の Lv までに要る量は `200 × Lv^1.63`（10単位で切り上げ）。Lv1→2 は 200 で、最初の BONUS で上がります。Lv20 までの合計は約18.8万で、中級者（正解85%・速答5割）の甘デジなら約4,600問（BONUS の賞金が1問あたり約38 yan ＋ 正解の 3）。Lv20 から先は自己満足です（`src/ui/level.ts`）。
- **物語（パチふとくんの記憶。ヘッダーの本のマーク）**：パチふとで経験を積むほど、パチふとくんの失った記憶が流れ込んでくる、という設定。Lv N で第N話が読め、**Lv20 の第20話で完結**（事実上のクリア）。平和な時代のパチンコ屋に並ぶ人気筐体だった頃、常連のゲンさん、勝ち点で人を測る「勝者法」と yan の始まり、ホールが賭場に変わっていく世紀末、筐体に意識が宿った夜、封印された記憶とプレイヤー（新顔）との出会いまで。まだ読めない話は「Lv N で読める」と伏せて出します。Lv が上がると一言ガイドで知らせ、「読む」でその話を開きます。文は `src/ui/story.ts`（1話 約250〜330字）。

**収支の目安**（甘デジは4万問×4回、ミドル・MAX は10万問×4回のシミュレーションの平均）

| プレイヤー | 早見 | 符計算 | 実戦 | ミドル | MAX |
|---|---|---|---|---|---|
| 上級（正解率95%・速答8割） | 311% | 265% | 260% | 259% | 251% |
| 中級（正解率85%・速答5割） | 116% | 113% | 118% | 121% | 118% |
| 下位（正解率75%・速答3割） | 65% | 60% | 61% | 62% | 63% |
| 初心者（正解率60%・速答2割） | 32% | 25% | 28% | 27% | 28% |

- 目標は「中級者が約115%、上級者が約250%」。速答の BET 半額と電チュー（連続正解で玉2個）は、上級者ほど得をする仕組みなので、BONUS の連続正解・全問正解の倍率は小さくして差を抑えています。早見は連続正解が続きやすく、上級者は少し高め（約310%）です。
- 中級者が増やせる yan は、甘デジで100問あたり約450〜600、ミドル・MAX で約1,100〜1,200 です。
- 価格はこの稼ぎに合わせています。中級者なら、最初の景品（1,500）は甘デジで約300問、ミドルの解放（3,000）は約600問、MAX の解放（10,000）はミドルで約900問。景品と台を全部そろえるには、合わせて約1万問です。
- 振れ幅は、300問のセッションを150回まわしたときの回収率の標準偏差です。

**そのほか**
- 保留の先読み、発展リーチ（擬似連・PUSH ボタン・カットイン）、確定演出、RUSH、成績を見る（正答率・収支・スランプグラフ・大当り履歴を出して区切る。所持金と台はそのまま）、破産と再起があります。「成績を見る」は出題設定の下にあります。
- BGM：BONUS 中は BONUS の曲、RUSH 中は RUSH の曲が流れます（演出がオフのときは鳴りません）。スマホのスピーカーでも聞こえるよう、中高音のメロディで作っています。
- 連続正解：10連・20連…の節目に大きな数字と細い線だけの表示。問題数の横の「N連」は5連で太字、10連で下線が光り、20連でホログラムの色になります。
- コインの演出は、実際にお金が入るとき（BONUS の賞金・上乗せ・払い出し）だけに出します。通常時の満貫・跳満は役名と火花だけです。
- 演出の強さは設定で変えられます。画面のフラッシュは1秒に2回まで、1回の演出で3回までに抑えています。

#### 稽古：手牌を段階的に解いて、数え方を身につけるモード

- パチンコ要素（台・演出・効果音・コンボ表示・yan）はすべて外しています。スコア・自己ベスト・制限時間はありません。
- 種目（早見・符計算・実戦）はなく、**手牌1つを段階に分けて解く練習**だけです。上部の切り替えは2段です。
  - 1段目：学習モード **重点学習｜簡易学習**
  - 2段目：出題 **通常｜苦手｜復習（N）**
- **重点学習**（7段階。当てはまらない段階は飛ばす）
  1. 基本符・アガり方：副底20符に、門前ロン +10／ツモ +2 を足すか
  2. 面子の符：刻子・槓子ごとに1問（手牌の該当する面子が光る）。刻子・槓子がなければ表示だけで次へ
  3. 雀頭の符：役牌・場風・自風の頭か
  4. 待ちの符：待ちの形（両面・嵌張・辺張・双碰・単騎）
  5. 符を確定：合計して切り上げ（七対子25・平和ツモ20・喰い平和30 の例外も）
  6. 翻を数える：1〜4翻・満貫・跳満・倍満以上（入力では翻数）
  7. 点数：親子・ロンツモに応じた点数
  - 手牌は面子ごとに区切って見せ（答えになる符・面子の種類・待ちは隠す）、答えた分の符を「副底20 ＋10 ＋8 … ＝ 38符 → 40符」の帯に積み上げます。七対子は1〜4を飛ばします。
- **簡易学習**：符を確定 → 翻 → 点数 の3段階。
- どちらも、間違えた段階はその場で正解と理由を見せ、正しい値で次の段階に進みます（後の段階が巻き添えで外れない）。全段階が正しければ正解です。最後に役・符・点数の解説が出ます。
- **出題設定**：回答（選択／入力）・問題数（10・25・50・無制限）・鳴き（すべて／門前／副露）・親子・和了。入力では符・翻・点数を数字で打ちます（待ちの形だけは選びます）。
- **復習**：パチンコ・稽古のどちらでも、間違えた手牌の問題は保存されます（最大100問。早見は除く）。出題で「復習」を選ぶと古い順に段階練習で出し、2回続けて正解すると一覧から外れます。
- **苦手**：要素（基本符・面子・雀頭・待ち・符・翻・点数）ごとの正答率を記録し、正答率の低い要素でつまずきやすい手を多めに出します。要素ごとに5問以上の記録がたまってから使えます。
  - 稽古では段階ごとに記録します。パチンコでは、正解ならその手の要素をすべて正解とし、不正解なら誤答の診断が当たった要素だけを誤りとします。
  - 稽古の結果画面に要素別の正答率（これまでの累計）を出します。記録は設定の「稽古の記録」で消せます。

#### 誤答の診断（パチンコ）

符計算・実戦で不正解だったとき、答えが典型的なミスをしたときの値と一致すれば「その答えは『ロンで完成した刻子を暗刻で数えた』場合の値です」と1行で伝えます。対象のミスは、ツモ符の付け忘れ・平和ツモにツモ符を付ける・門前ロンの10符の付け忘れ・么九牌の刻子を2倍にし忘れる・ロンの刻子を暗刻で数える・待ちの2符の付け忘れ・喰い平和形を30符にしない・切り上げ忘れ（入力モード）・点数が低くなる分け方で数える、です。ミスの値は点数エンジンで計算し直すので、正解とずれません。正解と同じ値になるミスや、どのミスとも合わない答えには何も言いません。

#### 出題の符の分布

70符以上になるのは、么九の暗刻や槓子がいくつも重なった手だけで、実戦ではまれです。そのため、**どのモードでも70符以上は出題しません**（ヘルプの「符の数え方」タブにも説明があります）。60符も全体の数％だけで、30符と40符が中心です。

#### 演出の設定

- パチンコの演出の強さは「全開／控えめ／オフ」から選べます。OS で「視差効果を減らす」を有効にしている場合は、初期値が「控えめ」になります。
- 画面のフラッシュは1秒に2回まで、1回の演出で3回までに抑えています。

### Android アプリ（Capacitor）

Google Play 向けに、同じ `src/` を [Capacitor](https://capacitorjs.com/) で Android アプリにしています（アプリID `io.github.konja9.pachifuto`）。`android/` が Android Studio のプロジェクトです。

```bash
npm run android        # Web をビルドして android/ に反映（cap sync）
npm run android:open   # Android Studio で開く（実機・エミュレータで実行、AAB の作成）
```

- 必要なもの：Android Studio（JDK 21・Android SDK を含む）。
- アプリの中身は APK に同梱し、通信なしで動きます。フォントも `@fontsource/*` で同梱しています（Web 版も同じ。woff2 だけを使うよう `vite.config.ts` で絞っています）。
- 戻るボタン：開いているダイアログか出題設定シートを閉じ、何も開いていなければアプリを背面に回します（`src/ui/native.ts`、`App.back()`）。
- 画面が隠れたら音を止め、戻ると再開します。画面は縦固定です。
- **上部バナー広告（AdMob）**：Android 版だけに出します（`src/ui/ads.ts`）。起動時に EEA・英国などでは同意フォームを出し、必要な地域では設定に「広告 › プライバシー設定」を出します。広告の高さ＋8px（液晶帯の誤タップ防止）を CSS 変数 `--ad-h` に入れて、画面全体を下げます。
  - `npm run android` の開発ビルドは**常に Google のテスト広告**です。開発中は本番広告を表示・タップしないでください（アカウント停止の対象）。
  - 本番の ID は2か所に書きます。AdMob の管理画面でアプリと広告ユニット（アダプティブ バナー）を作って発行します。
    - アプリ ID：`android/gradle.properties` の `ADMOB_APP_ID=ca-app-pub-…~…`（未設定ならテスト用 ID）
    - 広告ユニット ID：リポジトリ直下の `.env.release` に `VITE_ADMOB_BANNER_ID=ca-app-pub-…/…`
  - Play に出すビルドは `npm run android:release` で作ります（`.env.release` を読む）。
- **広告削除（買い切り 500円）**：Google Play の課金を `@capgo/native-purchases` で直接使います（`src/ui/purchase.ts`）。サーバーは使いません。
  - Play Console で **1回限りのアイテム**を ID `remove_ads`・価格 500円で作ります。
  - 設定の「広告」に「広告を消す（￥500）」と「購入を復元」を出します。広告が出ている間は、問題数・正答率の行の右端にも「広告を消す」を出し、押すと購入画面を開きます。買うとその場でバナーを消します。
  - 起動のたびに Google Play に購入を問い合わせ、買ってあれば広告を出しません。返金されると次の起動から広告に戻ります。通信できないときは前回の結果を使います。
  - コンビニ払いなどの支払い待ちは購入済みにせず、支払いが済んでアプリに戻ったときに反映します。
  - 実機で試すには、AAB を Play Console の内部テストに一度アップロードし、自分の Google アカウントを**ライセンス テスター**に登録します（テスト用のカードで、実際には請求されません）。
- **ストア掲載情報**：`store/listing.md`（アプリ名・説明文・分類）と、`store/` の画像（アイコン、フィーチャー グラフィック、スクリーンショット6枚）。画像は `npx -p playwright node scripts/store.mjs` で作り直します（元の画面は `store/raw/`）。
- バージョンは `package.json` の `version` から作ります（`1.2.3` → versionName `1.2.3`、versionCode `10203`）。Play に上げるたびに上げてください。

### 効果音
- 効果音 37本（`public/assets/sfx/*.mp3`、合わせて約420KB）は `tools/sfx.py` で合成しています。玉やコインは整数倍にならない倍音の金属音、リールの停止は低いドンとカチッという機械音、ファンファーレは金管風の和音とティンパニ・シンバル、それぞれにホールの残響をかけています。
- 作り直すとき：`pip install numpy` と ffmpeg を用意して `python3 tools/sfx.py`（`--wav` で確認用の WAV も残す）。音を足すときは `tools/sfx.py` に `@sound('名前', ピーク)` の関数を足し、`src/ui/audio.ts` の `SAMPLE_NAMES` に名前を加えます。
- アプリは最初のタップ（スタート画面からゲームに入るとき）で音を有効にし、ファイルを読み込みます。読み込み前・読み込めないときは、以前の Web Audio の合成音で鳴ります。音の高さを変える音（連続正解・段階・ラウンド）は再生速度で変えています。
- **UI のタッチ音**：ボタン・タブ・スイッチなどを押すと小さな「ポッ」（`tap`）、閉じるボタンは少し低い「ポン」（`tapClose`）。チュートリアルの吹き出しを送るとき、ローディング画面からゲームに入るときも鳴ります。4択とテンキーは今までどおり自分の音です。音を出さないボタンには `data-silent` を付けます。iPhone・Android・PC のどれでも再生できるよう MP3 にしています。
