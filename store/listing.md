# Google Play ストア掲載情報

Play Console の「ストアでの表示 → メインのストアの掲載情報」に、そのまま貼り付ける文面です。
画像は `npx -p playwright node scripts/store-raw.mjs http://localhost:5179/`（元の画面を撮る。開発サーバーを立ててから）→ `npx -p playwright -p tsx tsx scripts/store.mjs` で作り直せます。

## アプリ名（30文字以内）

```
パチふと：麻雀の点数計算をパチンコで練習
```

## 簡単な説明（80文字以内）

```
麻雀の点数計算・符計算を、パチンコの演出つきで楽しく練習。面子ごとの図解で、符の数え方が身につく。
```

## 詳しい説明（4000文字以内）

```
麻雀の点数計算、なんとなくで済ませていませんか？
「パチふと」は、退屈になりがちな点数計算と符計算の練習を、パチンコ台を回しながら楽しく続けられるトレーニングゲームです。
正解すると玉が入って台が回り、リーチ演出や大当りが続くので、飽きずに何問でも解けます。

■ パチンコモード：飽きずに、何問でも
・正解すると玉が入り、台が回ります。リーチ・擬似連・大当り・RUSH の演出つき
・大当りすると BONUS。正解した手の「符」が高いほど賞金が上がるので、符計算が身につくほど稼げます
・速く答えれば BET が半額、連続正解で電チュー。運だけでなく、計算の正確さと速さで差がつく台です
・出題は3種類：実戦（手牌から点数）・符計算（符だけ）・早見（「4翻30符・子のロン」の点数）
・甘デジ・ミドル・MAX の3種類の台。稼いだ yan で称号・スキン・BGM と交換できます

■ 稽古モード：一から点数計算を習得
・重点学習：副底20符から、アガり方・面子・雀頭・待ち・切り上げ・翻・点数まで、一段ずつ答えて数え方を身につける
・簡易学習：符 → 翻 → 点数の仕上げ
・答えたあとは、手牌を面子ごとに区切った図と、それぞれの符を全部表示。どこで符が付くのかが一目でわかります
・間違えた手は「復習」で解き直し、「苦手」では弱いところだけを集中して練習
・yan も演出も使わないので、じっくり集中できます

■ はじめてでも安心
・案内役の「パチふとくん」が、チュートリアルで遊び方から教えてくれます
・ヘルプでは符の数え方を図解カードで説明

■ 続けるほど、物語が進む
舞台は「ギャンブル世紀末」。人の値打ちが、勝ち取った点数だけで決まる時代です。
yan を稼いで Lv が上がるたびに、麻雀牌スロットの妖精・パチふとくんの失われた記憶が1話ずつ戻ってきます。全20話。
平和だった頃のパチンコ屋、そして世界がギャンブル世紀末になった理由とは——。

■ ルールの設定
喰いタン・赤ドラ・切り上げ満貫・数え役満・ダブル役満・連風牌の雀頭（2符/4符）を切り替えられます。

■ ご注意
・ゲーム内の通貨「yan」は練習の記録を楽しむためのもので、現実のお金で買うことも、換金することもできません。
・実際のパチンコやギャンブルとは関係ありません。
・画面上部に広告が表示されます。アプリ内の「広告を消す」（買い切り）を購入すると、広告が表示されなくなります。
・オフラインでも遊べます。

プライバシーポリシー：https://konja9.github.io/privacy.html
```
