# Google Play ストア掲載情報

Play Console の「ストアでの表示 → メインのストアの掲載情報」に、そのまま貼り付ける文面です。
画像は `npx -p playwright node scripts/store-raw.mjs http://localhost:5179/`（元の画面を撮る。開発サーバーを立ててから）→ `npx -p playwright -p tsx tsx scripts/store.mjs` で作り直せます。

## 簡単な説明（80文字以内）

```
麻雀の点数計算・符計算を、パチンコを回しながら覚える。図解で数え方が分かり、成績で伸びが見え、段位も上がる。
```

## 詳しい説明（4000文字以内）

```
麻雀の点数計算、なんとなくで済ませていませんか？
「パチふと」は、退屈になりがちな点数計算と符計算の練習を、パチンコ台を回しながら続けられるトレーニングゲームです。
正解すると台が回り、リーチ・大当り・RUSH が続くので、気づけば何十問も解いています。遊んでいるうちに、点数を数える手が速く、正確になっていきます。

■ パチンコ：正解で回り、符で稼ぐ
・正解すると玉が入り、台が回ります。擬似連・カットイン・PUSH ボタン・パチふとくんリーチなどの演出つき
・大当りすると BONUS。正解した手の「符」が高いほど賞金が上がるので、符計算が身につくほど稼げます
・速く答えれば BET が半額、連続で正解すれば電チュー。運だけでなく、正確さと速さで差がつく台です
・出題は3種類：実戦（手牌から点数）・符計算（符だけ）・早見（「4翻30符・子のロン」の点数）
・台は甘デジ・ミドル・MAX の3種類。重い台ほど、当りの一撃が大きくなります

■ 稽古：一から数え方を身につける
・重点学習：副底20符から、アガり方・面子・雀頭・待ち・切り上げ・翻・点数まで、一段ずつ答えて数え方を覚える
・簡易学習：符 → 翻 → 点数の仕上げ
・答えたあとは、手牌を面子ごとに区切った図と、それぞれの符を全部表示。どこで符が付くのかが一目で分かります
・間違えた手は「復習」で解き直し、「苦手」では弱いところだけを集中して練習

■ 上達が見える成績
・答えるたびに記録が残り、早見・符計算・実戦ごとに、直近50問の正答率と平均の速さを表示
・前の50問よりどれだけ伸びたか、遊んだ日ごとの推移をグラフで見られます
・苦手も分かります：親・子とロン・ツモの別、面子・雀頭・待ちなど符の要素ごと、早見でよく間違える点数
・次の昇段試験の基準と今の腕前を並べて、「あと何ポイント・あと何秒」まで教えてくれます

■ 段位と台の改造
・2 Lv ごとに「昇段試験」。5級から名人まで全10段階。後半は正解数だけでなく速さも問われます
・Lv が上がるたびに台の改造パーツが手に入ります。保留タンク・確変ユニット・ラウンド追加など全12種類
・試験に受かるたびにパーツを付ける枠が増え、ある雀士が遺した手書きの帳面が1頁ずつ戻ってきます。帳面には、数え方のコツが書かれています

■ 続けるほど、物語が進む
舞台は「ギャンブル世紀末」。人の値打ちが、勝ち取った点数だけで決まる時代です。
Lv が上がるたびに、麻雀牌スロットの妖精・パチふとくんの失われた記憶が1話ずつ戻ってきます。全20話。
平和だった頃のパチンコ屋、帳面を遺した雀士、そして世界がギャンブル世紀末になった理由とは——。
遊んでいる間も、パチふとくんが台の横で正解を喜び、街のうわさ話をしてくれます。

■ 交換所と音
・稼いだ yan で、称号・台のスキン・牌の背の色・BONUS の曲（ユーロビート・和風・ジャズ・メタルなど7曲）と交換できます
・場面ごとの BGM と効果音つき。音量は BGM と効果音で別々に調整できます

■ はじめてでも安心
・案内役のパチふとくんが、チュートリアルで遊び方から教えてくれます
・ヘルプでは、符の数え方を図解カードで説明

■ ルールの設定
喰いタン・赤ドラ・切り上げ満貫・数え役満・ダブル役満・連風牌の雀頭（2符/4符）を切り替えられます。

■ ご注意
・ゲーム内の通貨「yan」は練習の記録を楽しむためのもので、現実のお金で買うことも、換金することもできません。
・実際のパチンコやギャンブルとは関係ありません。
・画面上部に広告が表示されます。アプリ内の「広告を消す」（買い切り）を購入すると、広告が表示されなくなります。
・オフラインでも遊べます。
```
