# Google Play ストア掲載情報

Play Console の「ストアでの表示 → メインのストアの掲載情報」に、そのまま貼り付ける文面です。
画像は `npx -p playwright node scripts/store.mjs` で作り直せます。

## アプリ名（30文字以内）

```
パチふと：麻雀の点数計算をパチンコで練習
```

## 簡単な説明（80文字以内）

```
麻雀の点数計算・符計算を、パチンコの演出つきで楽しく練習。面子ごとの図解で、符の数え方が身につく。
```

## 詳しい説明（4000文字以内）

```
麻雀の点数計算、なんとなくで済ませていませんか？
「パチふと」は、点数計算と符計算を、パチンコ台を回しながら練習できるトレーニングゲームです。
正解すると台が回り、リーチ演出や大当りが続くので、飽きずに何問でも解けます。

■ 3つの出題モード
・実戦：手牌・場風・自風・ドラを見て、点数を答える
・符計算：符だけを答える。20符〜70符のボタンで、勘に頼らず数えて答える
・早見：「4翻30符・子のロン」の点数を答える。点数表の暗記に

答え方は4択と数字入力から選べます。子のツモ（1000-2000 など）や親のツモにも対応しています。

■ 間違えても、なぜその点数かがわかる
答えたあとに、手牌を面子ごとに区切った図と、それぞれの符を表示します。
副底・和了り方・面子・雀頭・待ち・切り上げの順に、0符の項目も含めて全部並べるので、どこで符が付くのかが一目でわかります。
分け方で符が変わる手は、別の分け方と「高点法」もあわせて説明します。

■ パチンコ台で楽しく続けられる
・正解すると玉が入り、台が回ります
・リーチ・擬似連・大当りなどの演出
・BONUS 中は連続正解で賞金が上がり、速く答えるほどお得
・甘デジ・ミドル・MAX の3種類の台（ミドルと MAX は yan で解放）
・ゲーム内の yan で、牌の背の色や台の見た目、BGM を交換できます
・ミッションと称号で、毎日の練習の目標に

■ 初めての人にもやさしい
・最初に3ステップの遊び方
・ヘルプでは「符の数え方」を図解カードで説明
・稽古モードでは演出を外して、数え方をじっくり身につけられます（出題の絞り込み・段階回答・間違えた手の復習・苦手ドリル）

■ ルールの設定
喰いタン・赤ドラ・切り上げ満貫・数え役満・ダブル役満・連風牌の雀頭（2符/4符）を切り替えられます。

■ ご注意
・ゲーム内の通貨「yan」は練習の記録を楽しむためのもので、現実のお金で買うことも、換金することもできません。
・実際のパチンコやギャンブルとは関係ありません。
・画面上部に広告が表示されます。アプリ内の「広告を消す」（買い切り）を購入すると、広告が表示されなくなります。
・オフラインでも遊べます。

プライバシーポリシー：https://konja9.github.io/privacy.html
```
