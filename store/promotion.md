# プロモーション戦略（パチふと）

## 前提
- 目標：**ダウンロード数**
- 費用：Google 広告の新規広告主キャンペーン **6万円**（条件・期限は Google Ads の画面で確認する）
- 発信の場：X、YouTube / TikTok
- 方針：広告収益で回収するのではなく、**最初のレビュー・順位の種・反応の良い訴求を知るため**に使う。おもな集客は無料の発信とストアでの見つかりやすさ（ASO）。広告は、その効き目を早く確かめる役

## 方針
1. 公開前に、動画・計測・受け皿を整える
2. 公開後2週間は、無料の発信で反応を見る
3. 3〜6週目に広告6万円を使い、訴求を比べる
4. 効いたものに寄せる（広告にも無料の発信にも）

## 発信の型

### X
- 毎日1本：ゲームの画面から作った「この手、何点?」の画像。答えは次の投稿
- ハッシュタグ：#麻雀 #麻雀初心者 #点数計算 #符計算
- 固定ポスト：ストアのリンクと、30秒の動画
- リンクには必ず流入元の印を付ける

### 縦動画（TikTok / YouTube Shorts）
- 15〜30秒。一つの驚きに絞る
  - 「符計算を3秒で」
  - 「パチンコを回すと点数が覚える」
  - 「この手、何点?（答え合わせ）」
- 最後はストアに誘導する一言

### YouTube の横動画
- ストア用に1本（`store/promo/promo-16x9.mp4`、撮り直したあと）
- 広告なし（収益化しない）・埋め込み許可・年齢制限なし

## ストアでの見つかりやすさ（ASO）
- 「点数計算」「符計算」「麻雀 練習」「点数早見表」を、アプリ名と説明の最初に入れる（今の名前はほぼ入っている）
- 1枚目のスクリーンショットは「麻雀の点数計算をパチンコで覚える」と一目で分かるもの
- レビューを増やす：昇段などの嬉しい場面でレビューを頼む案内を出す（Play の In-App Review。実装すると手間は増えるが、長く効く）
- 掲載情報の試験運用（A/B テスト）は、閲覧数が増えてから

## 広告（Google 広告・アプリキャンペーン）
- 種類：アプリキャンペーン（インストール最適化）
- 配分：日 2,000 円×30日で 6万円
- 判断：最初の1万円でインストール単価を見る。高すぎれば素材を作り直す。効く素材に寄せる
- 素材：見出し・説明文・画像・動画（撮り直したもの）
- 先に確認すること：Google 広告のギャンブルに関するポリシー。現金も換金もないが、パチンコの見た目なので、審査で止まらないか確かめる。文面に「実際の賭けではない」ことを入れておく
- 公開直後は、安定性を見てから出す

## 計測
- 流入元の印を付けたストアのリンクで、Play Console の「ユーザーの獲得」を見る
- 見るもの：ストアページの閲覧数、インストール率、インストール数、レビューの数と点数、クラッシュ・ANR
- 広告：使った額、インストール数、1インストールあたりの費用、素材別の成績

## リスク
- ギャンブル系の広告ポリシーで止まる
- クラッシュしたまま広告を出すと、悪いレビューが付く
- 自分で本番の広告（AdMob）をタップしない（アカウント停止の対象）
