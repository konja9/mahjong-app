# 0.2.0（クローズドテスト）

## Play Console の「このリリースの新機能」に貼る文（500文字以内）

```
大型アップデート
・Lv と物語：yan を稼ぐと Lv が上がり、パチふとくんの記憶（全20話）が1話ずつ戻ります
・昇段試験：2 Lv ごとに5級〜名人の試験。受かるたびに、ある雀士の帳面が1頁ずつ戻ります
・台の改造：Lv アップで改造パーツが手に入ります。台の5つの枠は、昇段試験に受かるたびに鍵が開きます
・成績：種目ごとの正答率と速さの伸び、日ごとの推移、苦手が見られます
・稽古：重点学習・簡易学習で、符の数え方を一段ずつ練習できます
・BGM：場面ごとの曲と、交換所の BONUS の曲。BGM と効果音の音量は別々に変えられます
・パチふとくんが遊んでいる間もしゃべります
・右上のメニューに、台選び・改造・昇段試験・交換所・物語・成績などをまとめました
※前の版のデータ（所持金・交換所の持ち物・設定）は引き継がれます。Lv と成績は今回から数えます
```

## テスターに試してほしいこと

1. **昇段試験と改造の枠**
   - Lv 2 で5級の試験を受けられます。受かると台の枠の鍵が1つ開き、改造パーツを付けられます
   - 試験の難しさ（特に初段から上の「平均の速さ」）が、きつすぎないか
2. **改造パーツ**
   - 付け替えて、台が「少し有利になった」と感じられるか。強すぎ・弱すぎはないか
3. **成績**
   - メニューの「成績」で、腕前・推移・苦手・台の4つのタブ
   - 何日か遊んだあと、伸びが分かるか
4. **音**
   - BGM と効果音の大きさ。設定で別々に変えられます
   - 長く遊んでも邪魔にならないか
5. **前の版（0.1.4）から更新した人**
   - 所持金・交換所の持ち物・設定が残っているか
   - Lv と成績は 1 / 記録なし から始まります（前の版にはなかったため）
6. **全体**
   - スマホで画面がずれる・隠れる・押しにくいところがないか
   - 物語や帳面の文で、読みにくいところがないか

## 出し方（手元で）

1. `npm ci`
2. `npm run android:release`（Web を作って Android に反映。`.env.release` の広告 ID を使う）
3. `npm run android:open` で Android Studio を開き、Build → Generate Signed App Bundle で AAB を作る（versionCode は 200）
4. Play Console → テスト → クローズド テスト → 新しいリリース に AAB を上げ、上の「新機能」の文を貼る
