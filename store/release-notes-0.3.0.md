# 0.3.0（クローズドテスト）

## Play Console の「このリリースの新機能」に貼る文（500文字以内）

```
・BONUS の連続正解の倍率が最大×2に。稼いだ yan で改造パーツを強化できます
・Lv は点数計算の実力で上がるように：正解するたびに経験値がたまります（早見・符計算・実戦の順に多く入ります）
・チュートリアルで出題の種類を自分で切り替え。迷ったら少し待つと正解が光ります
・ミドル台で符計算も遊べます。選べない種目のタブは鍵つきで表示
・稽古：効果音が鳴り、段階練習の点数が合えば「ほぼ正解！」、半分以上合えば「おしい！」
・点数表を追加（遊び方の「点数」タブと、実戦・稽古の答えのボタンの下）
・Google Play ゲームに対応：実績（15個）・ランキング・クラウドセーブ。機種を変えても続きから遊べます
・メニューに「実績・ランキング」を追加
・稽古の段階練習：手牌を画面に固定し、段階の一覧だけがスクロール
・物語の画面の左寄りを修正。「広告を消す」を画面上部に移動
```

## テスターに試してほしいこと

1. **Google Play ゲーム**
   - 起動するとログインのお知らせが出るか
   - メニューの「実績・ランキング」から、実績とランキングが開けるか
   - BONUS を引く・昇段試験に受かるなどで、実績が解除されるか
2. **クラウドセーブ**
   - メニュー → 実績・ランキング → クラウドに保存、が成功するか
   - 別の端末（またはアプリを消して入れ直した端末）で起動すると、「クラウドの記録を使うか」を聞かれ、続きから遊べるか
3. **稽古の段階練習**：スマホで重点学習を最後の段階まで進めても、上の手牌が見えたままか
4. **物語**：メニュー → 物語 の画面が、真ん中に出ているか
5. **BONUS の連続正解・パーツの強化**：BONUS で連続して正解するほど賞金の倍率が上がり、6問連続で×2になるか。改造の画面から、持っているパーツを yan で強化できるか
6. **経験値**：正解するたびに経験値の線が伸び、実戦ほど多く伸びるか。BONUS の賞金では伸びないか

## 出し方（手元で）

1. `store/play-games.md` の手順で Play Console を設定する。発行された ID を `android/app/src/main/res/values/games-ids.xml` と `src/ui/gamesIds.ts` に貼る
2. `npm ci` → `npm run android:release` → `npm run android:open`
3. Android Studio で署名付き AAB を作る（versionCode は 300）
4. Play Console のクローズドテストに上げて、上の「新機能」の文を貼る
   - ID を貼らずに出すと、Play ゲームの機能だけが出ない版になる（ほかの直しは入る）
